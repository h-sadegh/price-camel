# قیمت‌شتر (price-camel) 🐫

ردیاب تاریخچه قیمت برای فروشگاه‌های ایرانی — همتای ایرانی camelcamelcamel.

این پروژه هر ۶ ساعت قیمت محصولات مورد نظر شما را از API عمومی **ترب** (Torob) می‌خواند، در پوشه `data/` ذخیره می‌کند و اگر قیمت از حد هدف شما پایین‌تر بیاید، پیام هشدار به تلگرام می‌فرستد (فاز ۲).

همه‌چیز با **GitHub Actions** رایگان اجرا می‌شود — بدون سرور، بدون هزینه.

## ساختار پروژه

| فایل | کار |
|------|-----|
| `watched.json` | لیست محصولات تحت نظر (شما این را ویرایش می‌کنید) |
| `tracker.py` | قیمت فعلی هر محصول را می‌خواند و به تاریخچه اضافه می‌کند |
| `alerts.py` | قیمت آخرین نمونه را با قیمت هدف مقایسه و هشدار می‌فرستد |
| `data/<id>.json` | تاریخچه قیمت هر محصول: `[{"ts": ..., "price": ...}, ...]` |
| `.github/workflows/track.yml` | اجرای خودکار هر ۶ ساعت + کامیت داده‌ها |

## چطور کار می‌کند؟

- ترب یک API جستجوی عمومی دارد: `https://api.torob.com/v4/base-product/search/?q=...`
- endpoint جزئیات محصول پشت دیوار ضدربات است، بنابراین اسکریپت با جستجوی نام محصول و مطابقت `random_key` (همان شناسه یکتای محصول در URL ترب) قیمت را پیدا می‌کند.
- هر نمونه قیمت با timestamp ذخیره می‌شود. اگر قیمت نسبت به نمونه قبلی تغییر نکرده باشد، نمونه تکراری ثبت نمی‌شود.
- خطای شبکه، 404 یا مسدودسازی موقت API باعث کرش نمی‌شود — فقط همان محصول رد می‌شود.

## اضافه کردن محصول جدید

۱. در سایت torob.com محصول را پیدا کنید. URL چیزی شبیه این است:

   ```
   https://torob.com/p/c55049cc-f96c-4e17-a1f3-c68f74c2811c/...
   ```

   قسمت بعد از `/p/` همان شناسه محصول است.

۲. به `watched.json` اضافه کنید:

   ```json
   {
     "id": "c55049cc-f96c-4e17-a1f3-c68f74c2811c",
     "name": "شارژر اپل 20 وات",
     "query": "شارژر اپل توان 20 وات",
     "target_price": 4500000,
     "url": "https://torob.com/p/c55049cc-f96c-4e17-a1f3-c68f74c2811c/"
   }
   ```

   - `query`: عبارتی که محصول را در جستجوی ترب پیدا می‌کند (معمولاً نام محصول).
   - `target_price`: قیمت هدف به تومان — پایین‌تر از آن، هشدار می‌گیرید. اگر فعلاً هشدار نمی‌خواهید، `null` بگذارید.

۳. کامیت و پوش کنید. اجرای بعدی GitHub Actions محصول جدید را هم رصد می‌کند.

## سیستم هشدار (فاز ۲ — تلگرام)

`alerts.py` بعد از هر برداشت قیمت اجرا می‌شود. اگر آخرین قیمت ≤ قیمت هدف باشد، پیامی شبیه این ساخته و فرستاده می‌شود:

```
🐫 قیمت پایین آمد!
شارژر اپل 20 وات
قیمت فعلی: 4,300,000 تومان
قیمت هدف: 4,500,000 تومان
https://torob.com/p/...
```

هر هشدار فقط یک‌بار برای هر سطح قیمت فرستاده می‌شود (تا اسپم نشود) و اگر قیمت دوباره بالای هدف برود، هشدار مجدد فعال می‌شود.

## کجا Secret ها را تنظیم کنم؟

در گیت‌هاب: **Settings → Secrets and variables → Actions → New repository secret**

| نام Secret | مقدار |
|------------|-------|
| `BOT_TOKEN` | توکن ربات تلگرام (از @BotFather) |
| `CHAT_ID` | شناسه عددی چت شما (از @userinfobot) |

فعلاً بدون این دو مقدار هم همه‌چیز کار می‌کند — `send_telegram` فقط پیام را در لاگ چاپ می‌کند. **هرگز توکن را در چت یا فایل پروژه ننویسید؛ فقط در GitHub Secret.**

## اجرای دستی

```bash
python3 tracker.py    # برداشت قیمت‌ها
python3 alerts.py     # بررسی هشدارها
```

فقط به پایتون ۳ استاندارد نیاز دارد — هیچ کتابخانه‌ای نصب نمی‌شود.

## اجرای خودکار

فایل `.github/workflows/track.yml` هر ۶ ساعت (ساعت‌های 1، 7، 13، 19 UTC) اجرا می‌شود و داده‌های جدید را به همین ریپازیتوری کامیت می‌کند. از تب **Actions** می‌توانید دستی هم اجرا کنید (workflow_dispatch).
